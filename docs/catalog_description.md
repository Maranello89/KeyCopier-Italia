# KeyCopier Italia

Experimental Flipper Zero adaptation of KeyCopier with three CISA-style profiles (3, 4 and 5 positions), a pointed-V display and finer on-screen depth adjustments from 1 to 15.

Includes the original Select, Measure, Save and Load workflow.

**Important:** CISA geometry and levels are experimental visual measurements, not manufacturer-certified specifications. Use only on keys and locks that you own or are authorized to service. This is an independent community fork, not an official CISA product.

Based on [KeyCopier by zinongli](https://github.com/zinongli/KeyCopier). Original contributors are credited in the repository and the original MIT license is retained.
