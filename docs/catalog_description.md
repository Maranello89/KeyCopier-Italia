# KeyCopier Italia

Experimental Flipper Zero adaptation of [KeyCopier](https://github.com/zinongli/KeyCopier), adding CISA-style profiles with 3, 4 and 5 positions.

- Pointed V-shaped on-screen profile drawing
- Finer depth adjustment scale from 1 to 15
- Key format selection, measurement, Save and Load

The CISA-style dimensions and depth values are experimental and not manufacturer-certified. Use only on keys and locks you own or are authorized to work with.

Independent community adaptation. Not affiliated with CISA or Flipper Devices. Original KeyCopier authors and the MIT license are credited in the source repository.
